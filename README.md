# acxiom-crm

Role-based CRM application developed as part of the Acxiom technical assessment.

## Tech Stack

- ASP.NET Core MVC
- Entity Framework Core
- ASP.NET Core Identity
- SQLite
- Bootstrap
- Chart.js

## Roles

- Admin
- Manager
- Sales Executive

## Core Modules

- Authentication
- Dashboard
- Customers
- Leads
- Opportunities
- Follow-Ups
- Activities
- User & Role Management
- Audit Logs
- REST APIs
